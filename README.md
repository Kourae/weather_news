Steps on how to run our project:
1. Use Visual Code Studio.
2. Ensure that you already install extensions or other requirements to run project.
3. Clone this repository "final_bypair" to your VScode and ensure that the clone file is in htdocs but before that ensure that your VScode is connected to your GITHUB to get the clone easier.
4. Ensure that you already start you xampp Apache and Mysql for database purposes.
5. If you're already clone our project, I will provide the photo to have better understanding how to use our project.
